# Todoアプリ 要件定義

## 概要

- 単一ユーザーで利用するシンプルなTodo管理アプリ
- 認証機能なし

## 技術スタック

- バックエンド: Laravel（PHP 8.4）
- フロントエンド: Blade のみ（通常のフォーム送信＋リダイレクト。Livewire/Alpine/Inertia等は使用しない）
- データベース: SQLite

## データ項目

Todoタスクが持つ属性は以下のみ。

- タイトル（必須）
- 完了／未完了の状態

## 機能要件

- タスク一覧表示
  - 表示順は新しい順（作成日時の降順）
  - 完了済みタスクも未完了タスクと同じリスト内に表示する（取り消し線などで区別）
- タスク作成（タイトルを入力して登録）
- タスク編集（タイトルの変更）
- タスク削除
- タスクの完了／未完了の切り替え

## スコープ外（今回は対象外）

- ユーザー登録・ログイン等の認証機能
- タイトル以外の項目（説明文、期限、優先度、カテゴリ、タグ、サブタスクなど）
- 検索・絞り込み・並び替え機能
- 繰り返しタスク
- リマインダー通知
